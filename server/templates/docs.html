Pill Kit docs

Pill Kit puts a small widget from your app next to the clock: the macOS menu bar and the Windows taskbar. Use it for sponsors you sign yourself, launches, or live status. Every item is signed, labelled, and can be hidden by the person using the computer.

your app ──(SDK)──▶ pillkit-host ──(HTTPS, signed)──▶ Pill Kit server
                        │
                        └── draws the widget in the menu bar / taskbar
  • Your app ships the SDK. It talks to the host over a local socket.
  • pillkit-host is one small program per user. It owns the slot, so several apps share it fairly instead of fighting. It keeps showing your items when your app is closed.
  • The Pill Kit server (this site) holds your items and signs everything the host shows.

Quickstart

  1. Apply for a licence. Apply here. We review every developer by hand.
  2. Register your app on your dashboard. You get an appId and a publishable key (pk_…).
  3. Allow your links. In the app's Settings, add every site or app scheme your items may open, such as https://acme.com/ or acmeclip://.
  4. Create an item. Title, subtitle, icon, colours, and what happens on click. The editor shows a live preview.
  5. Add the SDK and call start(). Your item appears next to the clock within a few minutes.
npm install @pillkit/sdk
import { PillKit } from "@pillkit/sdk";

const bar = await PillKit.start({
  appId: "app_…",
  key: "pk_…",
  bundleId: "com.acme.clip",   // must match the portal, if you set one there
});

Licence and review

Pill Kit uses a one-time lifetime developer licence. It covers 3 apps with up to 20 items each.

  • Pending: you can sign in and look around.
  • Approved, invoice open: everything works; items carry a small Pill Kit dev label.
  • Active: paid, no label.
  • Revoked or suspended: your items switch off.

Node / Electron SDK

CallWhat it does
PillKit.start(opts)Connects to the host (installing and starting it the first time) and registers your app. Returns a PillKit.
bar.show(item)Shows your own item, such as a build status. It joins the rotation with your portal items.
bar.clear()Removes the items you showed with show().
bar.status()Licence state, item counts and the last error.
bar.on("callback", fn)Runs when someone clicks an item whose action is a callback.
bar.unregister()Stops showing anything for this app, even after restarts.
bar.close()Disconnects. Portal items keep showing.

Options: appId, key, bundleId, server (defaults to the Pill Kit cloud), hostPath (a custom host binary).

Electron: the host binary must sit outside the asar archive. Add "asarUnpack": ["**/node_modules/@pillkit/sdk/bin/**"] to your electron-builder config.

await bar.show({
  id: "build",
  title: "Build passed",
  subtitle: "main · 2 minutes ago",
  theme: { background: "#1F7A4D", foreground: "#FFFFFF" },
  action: { type: "callback", name: "open-build" },
});
bar.on("callback", (e) => openBuildWindow(e.item_id));

Items

Every item is drawn in the same 224 × 29 pt slot, so sponsors and status messages line up and the bar never jumps.

FieldLimitNotes
title40 charsBold first line. Required.
subtitle60 charsSecond line.
label16 charsSmall tag on the right. Sponsored items always have one (default "Sponsored").
icon64 KB PNGUpload any image in the editor; it's resized to 128 px. Without one, the first letter is used.
themehex coloursbackground and foreground.
card.body280 charsText in the card that opens on hover. Defaults to the subtitle.
weight1–100Higher shows more often within your app's turn.
duration_secs5–300How long it stays before the next item.
starts_at / ends_atUnix timeSchedule a launch or end a campaign automatically.

Rotation: apps take turns in the slot. Within your turn, your items rotate by weight.

Click actions

TypeFieldWhat happens
open_urlurlOpens a web page in the default browser.
deep_linkurlOpens a page in an app, like acmeclip://settings.
callbacknameTells your running app, through bar.on("callback").
cardOpens the card.

Links only open if they start with one of the app's allowed URL prefixes. A bare domain such as https://acme.com counts as https://acme.com/. file:, javascript: and similar are always blocked.

Hovering for half a second, or right-clicking, opens the card with the item's buttons plus Hide and Why this?.

Server API

Manage items from your own backend with the app's secret key (sk_…, shown once in Settings). Never ship it in your app.

curl {{ request.host_url }}v1/items \
  -H "Authorization: Bearer sk_…" \
  -H "Content-Type: application/json" \
  -d '{"title": "v2.1 is out", "kind": "status",
       "action": {"type": "deep_link", "url": "acmeclip://changelog"}}'
EndpointKeyPurpose
GET /v1/itemssecretList your items.
POST /v1/itemssecretCreate an item (same fields as above).
DELETE /v1/items/:idsecretDelete an item.
POST /v1/licensepublishableUsed by the host: a signed licence.
GET /v1/feedpublishableUsed by the host: signed items.
POST /v1/eventspublishableUsed by the host: shown and click counts.
GET /v1/public-keynoneThe key hosts use to check signatures.

macOS

A menu bar item to the left of the system icons. The pill is as tall as the menu bar allows (about 29 pt on a 33 pt bar). If macOS has no room beside the notch, the host steps down to a narrower width automatically. The host starts at login through a LaunchAgent, which appears in System Settings › General › Login Items.

Windows

Windows has no public API for the taskbar, so the host tries three modes in order:

  1. Embedded: the pill becomes part of the taskbar. On Windows 11 it sits on the left, where the weather widget lives, or beside it if the widget is on. On Windows 10 it sits just left of the tray.
  2. Overlay: a small always-on-top window over the same spot, hidden during full-screen apps.
  3. Tray: a notification-area icon with a tooltip. Always works.

It never covers the taskbar. The host reads where Start, Search, every app icon, the weather widget and the tray are, and puts the pill only in free space: beside the weather widget first, otherwise just left of the tray. If the full pill doesn't fit, it steps down until something does:

SizeShowsTypical taskbar
224 ptIcon, title, subtitle, labelRoomy: few pinned apps, or no weather widget
180 / 150 ptSame, with text shortenedModerately busy
120 pt (compact)Icon and title; the label shows on hoverBusy: weather widget plus many apps
Icon onlyYour icon in a squareVery crowded
TrayYour icon in the notification areaNo room at all (Windows 11 may tuck it behind ^)

It re-checks every 2 seconds, so it steps aside as apps open and grows back as they close. The item editor's Windows 11 taskbar preview shows your item at each size. Because the compact and icon sizes can't fit everything, keep the title short and recognisable and use an icon people know.

Force a mode with PILLKIT_WIN_MODE=embedded|overlay|tray. No code is injected into Explorer, so antivirus stays quiet. The host starts at login from HKCU\…\Run; no admin rights needed. Right-click opens the menu (the hover card is coming to Windows).

Linux

Planned: a tray item for KDE, Mint and XFCE, and a GNOME Shell extension. The host already runs on Linux for development and logs what it would show.

The host

pillkit-host run                     # what the login entry runs
pillkit-host install                 # copy to the user data folder, start at login
pillkit-host uninstall               # remove it and its cache
pillkit-host render item.json out.png
pillkit-host --version

Data folder: ~/Library/Application Support/pillkit (macOS), %LOCALAPPDATA%\pillkit (Windows). The log is host.log in that folder. When several apps bundle different host versions, the newest one wins.

Security

  • Licences and items are signed with Ed25519. The host rejects anything else.
  • Links are limited to each app's allowlist.
  • The local socket is per user; a process still can't show anything without a valid licence.
  • No personal data is collected; events are daily counts per item.

Report a vulnerability: see SECURITY.md.

Troubleshooting

My item doesn't appear.
Check it's switched on and not scheduled in the future. Hosts check for new items every few minutes. bar.status() shows the licence state and last error.
"This app can only open URLs you've allowed".
Add the link's site to the app's allowed URL prefixes, or use the one-click "Allow and save" button in the editor.
It shows "Pill Kit dev".
Your licence invoice is still open. The label disappears once it's marked paid.
The widget vanished on macOS.
The menu bar ran out of room. Quit an app with menu bar icons; the host also shrinks the pill to fit.
Nothing on Windows.
Check %LOCALAPPDATA%\pillkit\host.log. Try PILLKIT_WIN_MODE=overlay or tray.
